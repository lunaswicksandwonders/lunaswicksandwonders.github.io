Style Tile

This page documents the design system used across the project: the color palette, typography, and spacing rules.

Color Palette

Primary — Deep Lavender
#65527F
Used for the header background and major heading text. Soft Ivory text on this background checks at approximately 6.4:1.

Neutral Background — Soft Ivory
#FAF7F2
Used as the main page background and as light text on dark backgrounds.

Neutral Text — Deep Plum
#3D3548
Used for body text. Deep Plum on Soft Ivory checks at approximately 10.9:1.

CTA Accent — Ancient Gold
#7A5A16
Reserved for the main call to action. Ancient Gold with Soft Ivory text passes the 4.5:1 normal-text minimum.

Type Scale

Heading 1 — 2.5rem (40px)

Heading 2 — 2rem (32px)

Heading 3 — 1.5rem (24px)

Body text — 1rem (16px). Poppins is used for readable body copy.

Spacing Rules

  • main: max-width 800px, centered with margin: 0 auto, plus 40px top/bottom and 20px left/right padding.
  • h2: 8px bottom margin to keep the heading close to the paragraph that follows.
  • p: 32px bottom margin to separate ideas and content groups.
  • .cta: 16px top/bottom padding and 32px left/right padding.
