Style Tile

This page documents the design system used across this project: the palette, the typographic scale, and the spacing rules, so every page pulls from the same set of decisions instead of improvising fresh choices each time.

Palette

Primary — Deep Lavender #65527F
The primary brand color. Use for major headings, navigation elements, and important visual areas. Ivory text on this background has a strong accessible contrast ratio.

Neutral — Soft Ivory #FAF7F2
Used primarily for the page background and other large neutral areas. Deep Plum #3D3548 is used for body text.

Accent 1 — Dusty Lilac #D8BFD8
A softer secondary accent for cards, decorative elements, and subtle highlights. It should not be used for small text on the ivory background because the contrast is too low.

Accent 2 — Ancient Gold #7A5A16
Used sparingly for special details, icons, borders, and CTA elements. It provides stronger contrast against the soft ivory background.

Type Scale

Heading 1 — 2.5rem (40px)

Heading 2 — 2rem (32px)

Heading 3 — 1.5rem (24px)

Heading 4 — 1.25rem (20px)

Body text — 1rem (16px)

Spacing

  • main: max-width 800px, centered with margin: 0 auto, padding 40px top and bottom, 20px left and right.
  • Every h2: margin-bottom 8px, keeping a heading close to the paragraph it belongs to.
  • Every p: margin-bottom 32px, separating one topic from the next.
  • CTA button: padding 12px top and bottom, 20px left and right, with margin-top 24px.
  • Table cells: 0.75rem (12px) padding with a 1px Deep Lavender border.
