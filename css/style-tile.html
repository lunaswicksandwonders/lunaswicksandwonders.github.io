Style Tile

This page documents the design system used across this project: the palette, the typographic scale, and the spacing rules, so every page pulls from the same set of decisions instead of improvising fresh choices each time.

Palettes

Primary,Deep Lavender#65527f the primary brand color and can be used for major headings, navigation elements, and important visual areas which will pair with the soft ivory for the CTA button Ivory text on this background color checks at 6.4 to 1 which is slightly above the 4.5 to 1 minimum.

Neutral text Deep Plum #3d3548 on neutural background #faf7f2Body text and page background. Checks at 10.9 to 1, the highest pairing in the whole palette

Accent 1 Dusty Lilac #d8bfd8 a softer secondary accent for cards, decorative elements, and subtle highlights.Used for decorative accents due to the page background pairing with this accent is at 1.5 to 1 below the 4.5 to 1 minimum for text

Accent 2 Ancient Gold #7a5a16 Used sparingly to draw attention to special details,icons, borders and possibly premium icons. Could possibly be used with the background since it passes with a 5.9 to 1 slightly over the 4.5 to 1 minimum.

Type Scale

Heading 1 — 2.5rem (40px)

Heading 2 — 2rem (32px)

Heading 3 — 1.5rem (24px)

Heading 4-1.25rem(20px

Body text — 1rem (16px)

Spacing

  • main: max-width 800px, centered with margin: 0 auto, padding 40px top and bottom, 20px left and right.
  • Every h2: margin-bottom 8px, keeps a heading close to the paragraph it belongs to.
  • Every p: margin-bottom 32px, separates one topic from the next.
  • The call-to-action button: padding 16px top and bottom, 32px left and right, plus margin-top 24px to separate it from whatever sits above it.
